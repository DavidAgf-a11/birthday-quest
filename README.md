# Birthday Quest: Level 12

Персональная браузерная игра от старшего брата: три испытания, три ключа и секретный финал. Mobile-first, без сборки, CDN, аккаунтов, базы данных и платных сервисов. Все изображения нарисованы специально для проекта в SVG/Canvas; музыка и звуки синтезируются Web Audio и не используют чужие записи.

## Запуск на компьютере

Установленный Node.js нужен только для локального предпросмотра. В папке проекта выполните:

```sh
npm start
```

Откройте `http://localhost:4173`. Установка npm-пакетов не требуется. Чтобы остановить сервер, нажмите `Ctrl+C` в терминале. Другой порт: `PORT=8080 npm start`.

Также подойдёт расширение Live Server в VS Code. Не открывайте `index.html` двойным щелчком: ES-модулям нужен HTTP/HTTPS.

## Проверка на телефоне

1. Подключите телефон и компьютер к одной Wi-Fi-сети.
2. Запустите `npm start`. Сервер напечатает строку `Phone (same Wi-Fi)` с локальным адресом компьютера.
3. Откройте этот адрес в Safari на iPhone или Chrome на Android. При запросе macOS разрешите Node доступ к локальной сети.
4. Пройдите звёзды движением пальца, проверьте прыжки, все сундуки и финал. Поверните телефон во время игры, поставьте на паузу, сверните браузер и вернитесь.
5. Проверьте музыку на самом устройстве: браузер может учитывать беззвучный режим и системную громкость.

Локальный адрес доступен только в вашей сети. Для постоянного QR-кода нужна опубликованная HTTPS-ссылка. Service Worker и офлайн-режим на обычном локальном IP по HTTP недоступны; проверяйте их на GitHub Pages или на localhost.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `birthday-quest`.
2. Загрузите **содержимое этой папки** в корень репозитория. Файл `index.html` должен лежать рядом с папками `css`, `js`, `assets`, а не внутри дополнительной папки. Добавьте также `sw.js` и `.nojekyll`. `serve.mjs` и `package.json` нужны только для локального запуска; их можно оставить в репозитории.
3. Откройте **Settings → Pages → Build and deployment**.
4. В **Source** выберите **Deploy from a branch**, затем ветку **main**, папку **/(root)** и нажмите **Save**.
5. Дождитесь успешной публикации. Адрес сайта появится в Pages, обычно `https://USERNAME.github.io/birthday-quest/`.
6. Откройте именно этот адрес в приватной вкладке телефона и проверьте старт и все ресурсы. Абсолютных путей вида `/assets/...` в игре нет — она работает в подкаталоге репозитория.

Проект не требует серверных настроек, ключей API или GitHub Actions собственного авторства. Процедура выбора источника сверена с [официальной документацией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Ссылка для QR-кода

Скопируйте окончательную HTTPS-ссылку из Settings → Pages. Создайте QR-код для этой ссылки в используемом вами QR-генераторе или функции «Создать QR-код» браузера, если она доступна. Для карточки сохраните SVG или чёткий PNG.

Не кодируйте `localhost`, локальный Wi-Fi-IP или адрес файла. До печати откройте QR камерой телефона и проверьте читаемость маленького тестового образца. Оставьте свободное поле вокруг QR и хороший контраст; декоративные элементы располагайте вне кода.

## Изменение текста и подарка

- Старт, инструкции, сообщения уровней: `js/main.js`.
- Сумма, подпись к ней, поздравление и текст выдачи: `js/reward.js`.
- Цвета, размеры, адаптивность: `css/style.css`.
- Главная иллюстрация: `assets/world.svg`.
- Мелодия, громкость и звуки: `js/audio.js`.

В `reward.js` измените поля `amount` и `claim` согласованно. Поздравление разбито на `greeting` и `paragraphs`. Текст выводится с экранированием HTML. В стартовой странице, метаданных, карте, инструкциях и промежуточных победах приз не указан. Модуль награды подключается к интерфейсу только после финальной двери.

Секретность относится к обычному прохождению: статический сайт отдаёт исходные файлы браузеру, поэтому технически любопытный человек может найти текст награды в исходниках/офлайн-кеше. Это не платёжная система и не защита от взлома. Игра не запрашивает логины, пароли или платёжные данные.

## Сохранения и сброс

`localStorage` хранит полученные ключи, открытые сундуки, последний флажок Obby, просмотр финала и настройку звука. Сохранения привязаны к браузеру и адресу сайта. В приватном режиме они могут исчезнуть при закрытии вкладок.

- Перезагрузка сохраняет пройденные этапы. Незавершённая попытка ловли звёзд начинается заново; в Obby сохраняется флажок, в третьем уровне — открытые сундуки.
- «Начать уровень заново» открывает подтверждение. Ключи остаются; текущий уровень запускается с начала.
- «Сыграть ещё раз» в финале сбрасывает весь игровой прогресс, сохраняя настройку звука.
- Для полного сброса через консоль браузера:

```js
localStorage.removeItem("birthday-quest-level12-v1");
location.reload();
```

Если браузер запретил хранилище, игра работает в памяти и сообщает об этом. Повреждённые сохранения обрабатываются без падения приложения.

## Управление и правила

1. **Star Catcher:** ведите палец по полю, удерживая касание. Нужно поймать 12 звёзд за 30 секунд. Золотые и розовые дают по одной звезде; фиолетовый камень снимает одну. Счёт не опускается ниже нуля.
2. **Birthday Obby:** бег автоматический; касание поля или кнопки запускает прыжок. На пути шесть блоков и шесть пропастей, монетки и три флажка. Падение возвращает к последнему флажку. Короткий буфер прыжка и разрешение прыжка сразу после края помогают управлению.
3. **Mystery Chests:** четыре пары карточек; восемь огоньков; шифр с визуальными подсказками. Порядок сундуков свободный. Ошибки не ограничивают число попыток.

Пауза останавливает игровое время. При переходе на другую вкладку игра автоматически ставится на паузу. Звуки запускаются только после взаимодействия; кнопка динамика отключает музыку и эффекты вместе. Поддерживается системная настройка уменьшения движения.

## Офлайн и обновления

После успешной первой загрузки по HTTPS Service Worker кеширует все игровые ресурсы. Никаких внешних CDN нет. При отсутствии сети используются сохранённые файлы. Кеш не заменяет `localStorage` и не сбрасывает прогресс.

При изменениях игры увеличивайте суффикс `CACHE` в `sw.js`. При наличии интернета ресурсы обновляются из сети; повторно откройте страницу после публикации обновления. Полный офлайн-запуск требует завершённой установки Service Worker до потери связи.

js/icons.js         оригинальные SVG-иконки и сундуки
js/reward.js        секретное поздравление и награда
assets/            оригинальные SVG-иллюстрации
